# Termo em Python
Uma versão do famoso jogo TERMO feita em Python.<br>
Projeto para estudo de interface gráfica e outras bibliotecas famosas em Python.
<br><br>
O jogo TERMO consiste em uma palavra aleatória com 5 letras da língua portuguesa que é sorteada a cada jogo. O jogador precisa adivinhar que palavra é essa dentro de apenas 6 tentativas. A cada palavra que o jogador adiciona, as letras podem ter três cores: verde, amarelo e cinza. A cor cinza representa uma letra que não tem em lugar algum da palavra. Um quadrado amarelo é de uma letra que está na palavra, mas não naquela posição. E por fim, o quadrado verde é quando aquela letra está na palavra E na posição correta.<br>
O jogador vence a partida caso acerte a palavra dentro das 6 tentativas.
<br><br>
### Bibliotecas utilizadas
- Parte gráfica feita com biblioteca PyQt6 (escolhida por sua modernidade de widgets)
- Integração de planilha CSV com a biblioteca Pandas para adição de palavras
- Conversão de objetos da planilha para array com Numpy

*NOTA: O projeto ainda está em desenvolvimento, novas funcionalidades serão atualizadas e adicionadas ao longo do tempo.*
